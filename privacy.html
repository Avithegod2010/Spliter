Privacy Policy

Effective 2026-11-12 · applies to the Spliter Android app and this website

No accountsNo analyticsNo adsNo trackers

The short version

Spliter does all of its work on your device. It does not have a server, does not create accounts, and does not send your files, file names, or usage data anywhere.

What the app accesses

  • Files you pick. The app reads only the files and folders you select through Android's system file picker, in order to split or rejoin them. Everything happens locally in the app's native engine.
  • Local settings and history. Job history, theme settings, and preferences are stored on your device only. Uninstalling the app removes them.
  • No storage permissions. Spliter uses Android's Storage Access Framework, which grants access only to the exact files and folders you choose.

What the app does not do

  • No network requests of any kind during normal use — the app works fully offline.
  • No collection of personal data, device identifiers, or usage statistics.
  • No advertising, no third-party SDKs, no trackers.

This website

The marketing site at avithegod2010.github.io/Spliter is a static page hosted by GitHub Pages. It loads fonts from Google Fonts, which may record your IP address as part of serving font files, subject to Google's privacy policy. The site itself sets no cookies and runs no analytics. The same applies to this policy page.

Downloads and releases

App builds are distributed through GitHub Releases. Downloading from GitHub is subject to GitHub's privacy statement. The APK contains no telemetry and no crash reporting.

Children

Spliter does not collect any data from anyone, including children.

Changes

If this policy ever changes (for example, if optional crash reporting is added in a future version), the change will be published on this page and reflected in the app's store listing before the feature ships.

Contact

Questions or concerns: open an issue at github.com/Avithegod2010/Spliter/issues.
